# BeautyBomb Delivery

Независимый продуктовый концепт браузерной промоигры для портфолио. Проект не является официальной рекламной кампанией BeautyBomb.

## Быстрый старт

Требования: Node.js 22.12+ и npm.

```bash
npm install
npm run dev
```

Точечные проверки:

```bash
npm run typecheck
npm test
npm run build
```

`npm run verify` запускает все три проверки. Используйте его перед завершением функциональной фазы, а не после каждого изменения текста или ассета.

## Где искать контекст

1. `PRODUCT.md` — краткий долговечный продуктовый контекст.
2. `docs/PROJECT.md` — подробное поведение продукта и зафиксированные решения.
3. `docs/ART_BIBLE.md` и `docs/ASSET_MANIFEST.md` — визуальная система и производство ассетов.
4. `docs/ARCHITECTURE.md` — границы модулей и способ интеграции.
5. `docs/DECISIONS.md` — журнал материальных решений и текущая фаза.
6. `program.md` — короткий цикл работы агента.
7. `AGENTS.md` — правила изменения репозитория.

Следующая продуктовая фаза — серый прототип механики трёх полос.
