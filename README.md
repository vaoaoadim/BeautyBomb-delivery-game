# BeautyBomb Delivery

Независимый продуктовый концепт браузерной промоигры для портфолио. Проект не является официальной рекламной кампанией BeautyBomb.

## Быстрый старт

Требования: Node.js 22.12+ и npm.

\`\`\`bash
npm install
npm run dev
\`\`\`

Точечные проверки:

\`\`\`bash
npm run typecheck
npm test
npm run build
\`\`\`

\`npm run verify\` запускает все три проверки. Используйте его перед завершением функциональной фазы, а не после каждого изменения текста или ассета.

## Где искать контекст

1. \`docs/PROJECT.md\` — продуктовая спецификация и зафиксированные решения.
2. \`docs/ARCHITECTURE.md\` — границы модулей и способ интеграции.
3. \`docs/DECISIONS.md\` — журнал материальных решений и текущая фаза.
4. \`program.md\` — короткий цикл работы агента.
5. \`AGENTS.md\` — правила изменения репозитория.

Следующая продуктовая фаза — серый прототип механики трёх полос.
